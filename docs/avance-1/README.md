## Cómo entregar

1. Completar nombres y matrículas en cada documento.
2. Agregar capturas de pantalla actuales de la app (Inicio, Escáner AR, Videos, Trivia, Stats, Marcadores).
3. Empaquetar el **proyecto completo** + carpeta `docs/avance-1/` en `.zip` / `.rar` con nombre y matrícula.

## Cómo correr el prototipo

```bash
npm install
npm start
```
