# Diamante 9 · Beisbol AR

App web de realidad aumentada (LMB) — proyecto LMAD · Procesamiento de Imágenes.

## Carpetas de assets (vacías para tus archivos)

```
public/assets/
  logos/      ← logo, favicon
  markers/    ← imágenes detonadoras AR
  videos/     ← clips del acervo
  models3d/   ← glTF / glb
  images/     ← fotos / posters
  fonts/      ← tipografías propias
  icons/      ← iconos
```

## Rutas

| Ruta | Función |
|------|---------|
| `/` | Landing |
| `/ar` | Escáner AR |
| `/videos` | Videos + filtros |
| `/trivia` | Trivia |
| `/estadisticas` | Stats simuladas |
| `/marcadores` | Guía de marcadores |
| `/juego` | Mini juego: Jonrón al toque |
| `/rebote` | Mini juego: Hockey de rebote |

## Cómo correr

```bash
npm install
npm start
```

`http://localhost:2000`
